缓冲区分析 ​

TdtBufferTool 封装天地图 BufferTool 扩展。拖动传入的多边形或圆会生成缓冲区，继续拖动缓冲区边缘可调整半径。组件会自动加载 turf 与 BufferTool 插件。

示例 ​

查看代码
vue
<template>
  <div class="demo-toolbar">
    <label><input v-model="active" type="checkbox" /> 启用拖拽</label>
    <button type="button" @click="bufferRef?.clear()">清除缓冲区</button>
    <span>{{ message }}</span>
  </div>
  <p v-if="errorMessage" class="demo-error" role="alert">{{ errorMessage }}</p>
  <div class="buffer-tool-demo-map">
    <tdt-map :center="center" :zoom="11">
      <tdt-polygon :path="polygonPath" color="#1677ff" :fill-opacity="0.2" @init="polygon = $event" />
      <tdt-circle :center="circleCenter" :radius="2500" color="#22c55e" :fill-opacity="0.2" @init="circle = $event" />
      <tdt-buffer-tool
        ref="bufferRef"
        :layers="layers"
        :active="active"
        :style="{
          color: '#ef4444',
          weight: 2,
          opacity: 0.8,
          fillColor: '#fecaca',
          fillOpacity: 0.35,
          lineStyle: 'dashed'
        }"
        @drag-start="message = '开始拖动…'"
        @drag="onDrag"
        @drag-end="onDragEnd"
        @error="onError"
      />
    </tdt-map>
  </div>
</template>

<script setup lang="ts">
import { computed, ref, shallowRef } from "vue";
import type { BufferToolExposed } from "../../../../packages";

const center = [113.280637, 23.125178] as [number, number];
const circleCenter = [113.33, 23.13] as [number, number];
const polygonPath = [
  [113.22, 23.16],
  [113.28, 23.17],
  [113.3, 23.11],
  [113.24, 23.1]
] as [number, number][];
const polygon = shallowRef<T.Polygon>();
const circle = shallowRef<T.Circle>();
const layers = computed(() => [polygon.value, circle.value].filter(Boolean) as (T.Polygon | T.Circle)[]);
const bufferRef = ref<BufferToolExposed>();
const active = ref(true);
const message = ref("拖动多边形或圆生成缓冲区");
const errorMessage = ref("");

function onDrag(event: T.BufferToolEvent) {
  if (event.radius != null) message.value = `缓冲区半径约 ${Math.round(event.radius)} 米`;
}
function onDragEnd(event: T.BufferToolEvent) {
  message.value = event.radius != null ? `已生成缓冲区，半径约 ${Math.round(event.radius)} 米` : "缓冲区已更新";
}
function onError(error: unknown) {
  errorMessage.value = error instanceof Error ? error.message : String(error);
}
</script>

<script lang="ts">
export default { name: "DemoBufferTool" };
</script>

<style scoped>
.buffer-tool-demo-map {
  width: 100%;
  height: 420px;
}
</style>

按需引入 ​

ts
import { TdtMap, TdtPolygon, TdtCircle, TdtBufferTool } from "vue-map-tianditu";
import type { BufferToolExposed } from "vue-map-tianditu";

layers 接收原生 T.Polygon / T.Circle 实例。通常通过覆盖物组件的 init 事件获取：

vue
<tdt-map :center="center" :zoom="11">
  <tdt-polygon :path="path" @init="polygon = $event" />
  <tdt-circle :center="center" :radius="2000" @init="circle = $event" />
  <tdt-buffer-tool :layers="layers" />
</tdt-map>
ts
const polygon = shallowRef<T.Polygon>();
const circle = shallowRef<T.Circle>();
const layers = computed(() => [polygon.value, circle.value].filter(Boolean) as (T.Polygon | T.Circle)[]);

属性 ​

属性类型默认值说明
layers(T.Polygon | T.Circle)[][]参与缓冲区分析的图形实例
activebooleantrue是否启用拖拽生成/调整缓冲区
styleT.BufferToolStyle见下文缓冲区样式

默认样式为 { color: "red", weight: 3, opacity: 0.5, fillColor: "#FFFFFF", fillOpacity: 0.5, lineStyle: "dashed" }。

layers 替换或原地修改时，组件会先解除旧图形的拖拽监听、清空已有缓冲区，再绑定新列表。样式修改对新生成的缓冲区立即生效，已有缓冲区保留原样式。

事件 ​

事件参数说明
initT.BufferTool工具初始化完成
drag-startT.BufferToolEvent开始拖动图形或缓冲区
dragT.BufferToolEvent拖动中，radius 为当前半径
drag-endT.BufferToolEvent拖动结束，radius 为最终半径
errorError初始化或同步失败

方法 ​

通过组件 ref 调用：

方法说明
open() / close()启用或停用拖拽
clear()清除所有缓冲区，保留原始图形
getTool()获取原生 T.BufferTool
getBufferLayers()获取当前地图上的缓冲区图层

使用边界 ​

  • BufferTool 会直接修改传入图形的行为，图形实例只能交给一个工具或分组管理。
  • clear() 只移除缓冲区，不删除原始多边形/圆；如需移除原始图形，请通过对应组件的 visible 或数组数据控制。
  • 计算依赖 turf@3（随插件自动加载）。离线部署时可通过 pluginUrls 覆盖 CDN 地址。
  • 缓冲区是工具生成的 T.Polygon / T.Circle，不会自动加入 TdtLayerGroup。
  • 插件依赖 CDN；不可达时组件通过地图的 error 事件上报。
