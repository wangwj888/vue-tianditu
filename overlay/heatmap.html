热力图 ​

TdtHeatmap 根据经纬度和权重绘制 Canvas 热力图。组件内核随应用打包并按需加载，无需配置天地图的 HeatmapOverlay 外链扩展。

示例 ​

查看代码
vue
<template>
  <div class="demo-toolbar">
    <button type="button" @click="replaceData">更新数据</button>
    <button type="button" @click="data = []">清空</button>
    <label><input v-model="visible" type="checkbox" /> 显示热力图</label>
    <label>半径 {{ radius }} px <input v-model.number="radius" type="range" min="10" max="70" /></label>
    <label
      >配色
      <select v-model="palette">
        <option value="warm">暖色</option>
        <option value="cool">冷色</option>
      </select></label
    >
    <span>{{ data.length }} 个数据点</span>
  </div>
  <p v-if="errorMessage" class="demo-error" role="alert">{{ errorMessage }}</p>
  <div class="heatmap-demo-map">
    <tdt-map :center="center" :zoom="12" @error="onError">
      <tdt-heatmap :data="data" :max="100" :radius="radius" :gradient="gradient" :visible="visible" @error="onError" />
    </tdt-map>
  </div>
</template>

<script setup lang="ts">
import { computed, ref } from "vue";

const center = [113.280637, 23.125178] as [number, number];
let generation = 0;
function createData() {
  return Array.from({ length: 80 }, (_, index) => ({
    lng: center[0] + ((index % 10) - 4.5) * 0.008,
    lat: center[1] + (Math.floor(index / 10) - 3.5) * 0.006,
    count: ((index * 17 + generation * 29) % 100) + 1
  }));
}
const data = ref(createData());
const radius = ref(32);
const visible = ref(true);
const palette = ref("warm");
const errorMessage = ref("");
const gradient = computed<Record<number, string>>(() =>
  palette.value === "warm"
    ? { 0.2: "#2563eb", 0.45: "#22c55e", 0.7: "#facc15", 1: "#ef4444" }
    : { 0.2: "#312e81", 0.45: "#7c3aed", 0.7: "#06b6d4", 1: "#a7f3d0" }
);
function replaceData() {
  generation++;
  data.value = createData();
}
function onError(error: unknown) {
  errorMessage.value = error instanceof Error ? error.message : String(error);
}
</script>
<script lang="ts">
export default { name: "DemoHeatmap" };
</script>
<style scoped>
.heatmap-demo-map {
  width: 100%;
  height: 380px;
}
select {
  border: 1px solid var(--vp-c-divider);
  border-radius: 4px;
  padding: 2px 6px;
}
</style>

按需引入 ​

ts
import { TdtMap, TdtHeatmap } from "vue-map-tianditu";

将热力图放在 TdtMap 内。数据项使用 lng（经度）、lat（纬度）、count（非负权重）。radius 单位为像素；地图缩放后坐标重新投影，半径保持屏幕像素大小。

属性 ​

属性类型说明
data{ lng: number; lat: number; count: number }[]热度点；空数组清空画面
maxnumber热度上限；不传时根据全部数据的最大权重计算，拖动地图不会改变色阶
radiusnumber每个点的影响半径，单位像素；默认 40
gradientRecord<number, string>0 到 1 的色阶与 CSS 颜色映射
blurnumber模糊程度，范围 0 到 1；默认 0.85
minOpacitynumber最小透明度，范围 0 到 1；默认 0
maxOpacitynumber最大透明度，范围 0 到 1；默认 1
visibleboolean控制显隐，默认 true

非有限值、越界经纬度和非正权重会被过滤；0 权重不绘制。支持响应式替换数据数组和更新样式。组件不会修改传入的数据；对大量数据建议一次替换数组，合并业务侧的多次更新。

事件和方法 ​

事件说明
init热力图初始化完成，返回组件实例接口
error渲染内核加载、初始化或绘制失败，参数为 Error

init 参数为 HeatmapHandle，包含 overlay、getElement() 和 refresh()。也可通过组件 ref 调用 refresh() 请求重绘。

热力图为连续 Canvas 图像，不提供逐点点击事件。需要点击标记时可以叠加 TdtMarker 或 TdtCustomOverlay。

更新与生命周期 ​

地图移动、缩放、容器尺寸变化时重绘；尺寸变化时重建画布并恢复当前数据。空数据清空画面，visible 控制显隐；卸载时清理画布、监听器和待执行的绘制任务。绘制只在客户端执行。

热力数据较多时应避免同时创建大量 DOM 覆盖物。涉及逐点展示的场景可以使用点聚合或海量点组件。
