右键菜单 ​

天地图 4.0 没有官方 T.ContextMenu 类，只提供地图 contextmenu 事件。TdtContextMenu 基于该事件实现一个可访问的 DOM 菜单，支持默认菜单项、完全自定义插槽、键盘导航和受控显隐。

示例 ​

查看代码
vue
<template>
  <div class="demo-toolbar">
    <label><input v-model="enabled" type="checkbox" /> 启用右键菜单</label>
    <span>{{ message }}</span>
  </div>
  <div class="context-menu-demo-map">
    <tdt-map ref="mapRef" :center="center" :zoom="12">
      <tdt-marker v-for="marker in markers" :key="marker.id" :position="marker.position" />
      <tdt-context-menu :items="items" :enabled="enabled" @open="onOpen" @select="onSelect" />
    </tdt-map>
  </div>
</template>

<script setup lang="ts">
import { ref } from "vue";
import type { ContextMenuEntry, ContextMenuContext, ContextMenuItem, TdtMap } from "../../../../packages";

const center = [113.280637, 23.125178] as [number, number];
const mapRef = ref<TdtMap>();
const enabled = ref(true);
const message = ref("在地图上点击右键打开菜单");
const markers = ref<{ id: number; position: [number, number] }[]>([]);
let nextId = 1;

const items: ContextMenuEntry[] = [
  { key: "zoom-in", label: "放大一级" },
  { key: "zoom-out", label: "缩小一级" },
  { type: "divider" },
  { key: "add-marker", label: "在此添加标记" },
  { key: "clear-markers", label: "清除全部标记", danger: true }
];

function onOpen(context: ContextMenuContext) {
  message.value = `右键位置：${context.lnglat[0].toFixed(5)}, ${context.lnglat[1].toFixed(5)}`;
}

function onSelect(item: ContextMenuItem, context: ContextMenuContext) {
  const map = mapRef.value?.getMap();
  if (item.key === "zoom-in") map?.zoomIn();
  else if (item.key === "zoom-out") map?.zoomOut();
  else if (item.key === "add-marker") {
    markers.value.push({ id: nextId++, position: [context.lnglat[0], context.lnglat[1]] });
    message.value = "已添加标记";
  } else if (item.key === "clear-markers") {
    markers.value = [];
    message.value = "已清除标记";
  }
}
</script>

<script lang="ts">
export default { name: "DemoContextMenu" };
</script>

<style scoped>
.context-menu-demo-map {
  width: 100%;
  height: 380px;
}
</style>

按需引入 ​

ts
import { TdtMap, TdtContextMenu } from "vue-map-tianditu";
import type { ContextMenuEntry, ContextMenuContext, ContextMenuItem } from "vue-map-tianditu";

将组件直接放在 TdtMap 内。组件渲染一个绝对定位的锚点，菜单定位在地图容器内；不要放进 TdtLayerGroup 等会隐藏子节点的容器。

属性 ​

属性类型默认值说明
itemsContextMenuEntry[][]菜单项；{ type: "divider" } 为分隔线
enabledbooleantrue是否响应地图右键
visibleboolean—受控显隐；不传时由组件内部管理
offset[number, number][0, 0]相对鼠标位置的偏移
closeOnSelectbooleantrue点击菜单项后是否自动关闭
closeOnMovebooleantrue地图平移、缩放、拖拽时是否关闭
minWidthnumber160菜单最小宽度，单位像素
maxWidthnumber320菜单最大宽度，单位像素
zIndexnumber1200菜单层级

自定义菜单 ​

默认插槽会替换整个菜单内容，插槽参数包含 lnglat、containerPoint、items、visible、select 和 close：

vue
<tdt-context-menu @select="onSelect">
  <template #default="{ lnglat, close }">
    <div class="my-menu">
      <button @click="addPoint(lnglat); close()">添加点</button>
      <button @click="showWeather(lnglat); close()">查看天气</button>
    </div>
  </template>
</tdt-context-menu>

需要自定义单项外观时，使用 item 插槽。插槽内容负责自己的点击与键盘行为；需要保留默认行为时，请直接使用默认菜单项渲染。

vue
<tdt-context-menu :items="items">
  <template #item="{ item }">
    <span class="my-item">{{ item.label }}</span>
  </template>
</tdt-context-menu>

交互与可访问性 ​

  • 菜单使用 role="menu" / role="menuitem"，打开后自动聚焦第一项。
  • ↑ / ↓ / Home / End 移动焦点，Enter / 空格触发，Esc 关闭。
  • 点击菜单外部、地图左键或地图移动时关闭。
  • 右键事件会阻止浏览器默认菜单；enabled=false 时不拦截。
  • 菜单打开期间会保存并恢复之前的焦点。
